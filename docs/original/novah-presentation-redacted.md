Development of a Voice-Automated software for People with Disabilities, our team has crafted a solution that not only meets current community needs but also evolves with time. Utilizing the Kanban process, we've deeply understood our audience's requirements, ensuring our solution is tailored to their needs, especially focusing on assisting individuals with impairments. 



About the Project


Project Vision 
The focus is on improving computer accessibility for individuals with disabilities.
The approach involves the creation and implementation of a voice-automated tool.
The tool aims to facilitate easier and more seamless computer usage for people with disabilities.
The goal is to empower individuals with disabilities to access and utilize computer technology more efficiently and independently.


Challenges Faced by People with Disabilities
Physical Limitations
Navigating the User Interface
Operating Input Devices
Accessing Controls and Buttons



Minimum Viable Product: Nova Project The Nova Project offers a voice-activated assistant designed for individuals with disabilities, focusing on simplifying digital navigation and daily tasks. 

Applications & Tasks: Open apps, create folders and take notes.
Information Retrieval: Perform web scraping, fetch weather updates, and answer questions using Wikipedia and jokes APIs.
Media Management: Access YouTube and control music playback via voice commands. Authentication: Secure access through face and hand recognition. 
Natural Interaction: Natural language processing based interactions
